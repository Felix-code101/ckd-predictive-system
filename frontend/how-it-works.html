How It Works

An in-depth look at the technology, models, and clinical research behind our CKD prediction system.

📋 System Overview

Our CKD Prediction System uses a trained Random Forest Classifier to analyze clinical biomarker data and predict the probability of Chronic Kidney Disease. The system is designed for decision support and academic research:

👨‍⚕️

Healthcare Practitioner Mode

Full clinical interface with 14 standardized biomarker inputs organized in a streamlined single-page workflow. Provides detailed health score, biomarker status grid, and feature importance chart for in-depth analysis.

Step by Step

The Prediction Pipeline

1

Data Input

The practitioner enters clinical biomarker values via the web form. All 14 parameters are entered directly.

Parameters Include: Age, Gender, Weight, Height, BMI (auto-calculated), Systolic BP, Diastolic BP, Serum Creatinine, Blood Urea Nitrogen (BUN), Serum Albumin, Phosphorus, Serum Bicarbonate, Serum Calcium, Uric Acid.
2

Data Preprocessing & Scaling

The backend receives the 14-parameter JSON payload. Categorical variables are ordinal-encoded, missing inputs undergo KNN Imputation ($k=5$), and continuous variables are normalized using Min-Max Scaling $[0, 1]$.

Encoding Examples: Gender: "Male" → 1, "Female" → 0
3

Feature Vector Construction

The 14 encoded values are assembled into a feature vector in the exact column order expected by the trained model (matching NHANES dataset ordering).

Feature Order (14 features): age, gender, bmi, weight_kg, height_cm, bp_systolic, bp_diastolic, serum_creatinine, blood_urea_nitrogen, albumin_serum, phosphorus, bicarbonate, calcium, uric_acid
4

Random Forest Prediction

The feature vector is passed to the pre-trained Random Forest Classifier. The model consists of 100 decision trees trained on bootstrap samples, yielding an ensemble decision.

Output: Binary classification (CKD / No CKD) + probability score from $0\%$ to $100\%$.
5

Result Visualization

The prediction, probability, and input data are returned to the frontend dashboard view:

  • Risk Gauge: Semi-circle meter showing risk probability (Green $\rightarrow$ Orange $\rightarrow$ Red).
  • Health Score Ring: Circular score visualization ($100 - \text{Risk Percentage}$).
  • Parameter Health Grid: Per-biomarker assessment against clinical reference ranges.
  • Feature Importance Chart: Horizontal bar chart showing top decision drivers.

🧮 Model Training Methodology

1. Data Cleaning & Imputation

KNN Imputer ($k=5$) handles sparse missing values based on nearest patient physiological profiles.

2. Class Balancing

Random minority oversampling is applied exclusively to the training set to prevent model bias towards majority healthy classes.

3. Model Evaluation Benchmark
